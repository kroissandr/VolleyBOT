# Сохранение истории удалённых игр

`games` помечает удаление игры в `deleted_at` и сохраняет её строки, записи и расклады. Игра выходит из расписания и перестаёт занимать зал. История собственных записей и факты для дисциплины остаются доступны, а слот экземпляра серии остаётся занятым для генератора. Физическое удаление потребовало бы отдельно хранить эти факты и ключи, чтобы повтор генерации или запоздалая команда не меняли историю.
