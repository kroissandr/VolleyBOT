# JWT, сессии и проверка прав

`users` выдаёт короткоживущий access JWT и refresh-токен с ротацией. Использованный refresh становится недействительным, выход отзывает refresh. Повторное предъявление использованного refresh отзывает refresh-токены пользователя по правилу [предметной области](../domain.md#пользователь-users).

`users` и `games` проверяют подпись и срок access JWT. Для решений о доступе сервисы используют актуальную роль и бан из `users`. `games` дополнительно проверяет права на конкретную игру или серию по её владельцу. Если проверка пользователя недоступна, операция, для которой требуются права, отклоняется. Так ранее выданный JWT сам по себе не даёт права выполнить действие после бана или смены роли.
