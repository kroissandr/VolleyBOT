# Ограничение пересечений по залу

PostgreSQL гарантирует, что интервалы занятости двух неотменённых игр одного зала не пересекаются. Для этого `games` хранит полуоткрытый диапазон `occupied` и использует ограничение исключения GiST по равенству `hall_id` и пересечению диапазонов с `btree_gist`. Соседние игры могут стыковаться по времени, а игры разных залов могут идти параллельно.

Ограничение применяется при вставке и переносе игры, в том числе при генерации серии. Оно защищает от гонки между параллельными запросами. `games` возвращает понятную ошибку с конфликтующей игрой, а при генерации серии публикует событие о пропущенном экземпляре.
