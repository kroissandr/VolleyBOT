# VolleyBOT

Бэкенд любительского волейбольного клуба на Go: расписание разовых и повторяющихся игр, запись с листом ожидания, перемешивание игроков на равные команды, явка и автобан, уведомления в Telegram. Игроки работают через Telegram-бота, модераторы и администратор — через REST API.

Три сервиса в монорепозитории:

- **users** — регистрация, JWT, профили, роли, баны;
- **games** — площадки и залы, игры и серии, запись, лист ожидания, перемешивание, явка;
- **telegram** — бот и уведомления.

Стек: Go, PostgreSQL, gRPC, Kafka (transactional outbox), Redis, Prometheus, k6, testcontainers, Docker Compose.
